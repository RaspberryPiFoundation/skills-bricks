Servo motor

Do Raspberry Pi Output Movement

What does it do?

A positional servo moves its arm, called a horn, to a chosen position and holds it there.

Short pulses on its signal wire set the position. The motor and position control are built into the case.

Use it for steering, pointing or opening a flap. A continuous-rotation servo controls speed instead; it cannot use this example to choose an angle.

Code

Raspberry Pi

from gpiozero import Servo
from time import sleep

servo = Servo(16)
servo.mid()
sleep(2)
Test unloaded: the horn centres. Try min() or max() instead of mid(). Travel varies; stop if it binds or buzzes. Check lead order.

Wiring

Raspberry Pi 5
GPIO16 (pin 36) → signal; 5V (pin 4) → top + rail → servo red; GND (pin 34) → servo −. Small SG90-size servo only: the Pi powers it.
