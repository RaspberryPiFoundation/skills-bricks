Passive buzzer

Do Sound PWM

What does it do?

A passive buzzer needs fast pulses (PWM) to make sound. Changing their frequency changes its pitch: low or high notes.

Recognise it: check for passive, external drive or no oscillator on the packet. Both types can look identical; + only marks polarity.

Use a small 3.3 V GPIO-compatible piezo sounder.

Code

Raspberry Pi

from gpiozero import TonalBuzzer

buzzer = TonalBuzzer(12)

buzzer.play("A5")

Raspberry Pi Pico

from picozero import PWMBuzzer

# GP16, 2000 Hz, 50% duty
buzzer = PWMBuzzer(16, 2000, 32768)

buzzer.on()
Pi: try buzzer.play("A4"); silence with buzzer.stop(). Pico: try buzzer.freq = 1000; silence with buzzer.off(). Higher frequency means higher pitch. Beep speed is separate; both types can make rhythms.
