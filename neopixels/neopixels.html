NeoPixels

Do Output Light

What does it do?

A NeoPixel is a full-colour LED with a tiny controller built into it.

One data wire carries colour instructions, and each pixel passes the remaining instructions onwards.

The 3.3 V-compatible JST breakout shown here can connect directly to a Pi or Pico.

Code

Raspberry Pi

import board
import neopixel

pixels = neopixel.NeoPixel(board.D18, 1)

pixels[0] = (255, 0, 80)

Raspberry Pi Pico

from machine import Pin
from neopixel import NeoPixel

pixels = NeoPixel(Pin(28), 1)
pixels[0] = (255, 0, 80)
pixels.write()
This wiring is for the pictured 3.3 V-compatible breakout. Generic 5 V strips usually need a separate supply and a logic-level shifter.

Wiring

Raspberry Pi 5
GPIO18 → IN, 3V3 → VDD, GND → GND
Pico
GP28 → IN, 3V3 OUT → VDD, GND → GND
