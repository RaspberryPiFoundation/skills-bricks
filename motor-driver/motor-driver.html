Motor driver

Do Output Movement

What does it do?

A motor driver lets a low-power GPIO control a motor that needs more current.

The L293D contains H-bridges that can send current through a motor in either direction.

Two input pins choose forwards, backwards or stop, while the chip handles the motor current.

Code

Raspberry Pi

from gpiozero import Motor

motor = Motor(forward=17, backward=18)

motor.forward()

Raspberry Pi Pico

from picozero import Motor

motor = Motor(14, 15)

motor.forward()
This card powers one small 5 V motor from the board's 5 V rail. Use a separate motor supply for larger motors, with the grounds joined.

Wiring

Raspberry Pi 5
GPIO17 → IN1, GPIO18 → IN2; OUT1 and OUT2 → motor
Pico
GP14 → IN1, GP15 → IN2; OUT1 and OUT2 → motor
